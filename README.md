# table-pad — 株式リサーチ一括改修版

既存の table-pad の表・チャート・分析機能を残し、株式リサーチ周辺をまとめて拡張したファイル一式です。

## 含まれる機能
- 既存の表・グラフ・分析・CSV取込機能
- ウォッチリスト（追加、名前編集、お気に入り、削除、検索、JSON/CSV一覧入出力）
- 日足CSVの取込（J-Quants CLI CSVの `Date, Code, O, H, L, C, Vo` 列、および一般的な日付/終値列）
- CSVから計算する終値、前日比、出来高、20日単純移動平均、20日騰落率
- スクリーニング（お気に入り、コード、会社名、前日比、価格範囲、出来高、20日平均線上下）
- CSVデータから既存の株価チャート用テーブルを作成
- 日本株検索（主要銘柄の内蔵候補から検索・ウォッチリスト追加）とYahoo!ファイナンス検索へのフォールバック
- Yahoo!ファイナンス銘柄ページへのリンク
- スマホ/iPhone向けレスポンシブUI、ホーム画面追加用manifest、HTTPS配信時のService Worker

## 適用（Windows）
1. まず `C:\Users\norin\table-pad` フォルダー全体をバックアップします。
2. ZIPを展開し、中の `table-pad-modular` フォルダーにあるファイルとフォルダーを既存の `C:\Users\norin\table-pad` へコピーします。フォルダー構成を保ってください。
3. `index.html` をブラウザーで開きます。元の `index.html` はバックアップから戻せます。

## 使い方
1. 「株価CSVを取り込む」を押し、J-Quantsの日足CSVを選択します。複数ファイルをまとめて選択できます。
2. 銘柄コードと日付、終値列が必要です。J-Quants標準CSVはコードを自動認識します。
3. 価格・前日比・出来高・20日平均線の条件を指定すると、ウォッチリスト内の銘柄を絞り込めます。
4. 「チャート」は取り込んだCSVを既存アプリの株価チャート用テーブルへ渡します。
5. 「日本株を検索」に会社名またはコードを入れて「銘柄を検索」を押すと、内蔵の主要銘柄候補を検索できます。見つからない場合は「Yahoo!で検索」で市場全体を検索できます。候補は「リストに追加」で登録できます。
6. Yahoo!リンクは銘柄ページを開きます。Yahoo!からの価格自動取得は行いません。

## iPhoneの注意
- iPhone SafariではCSV取込、ウォッチリスト、スクリーニング、既存の表・チャートを利用できます（実機確認は利用者側で必要です）。
- ホーム画面追加/PWAキャッシュはHTTPSで配信した場合に有効です。ローカルの `file://` で開いた場合はService Workerは動きません。
- WindowsのJ-Quants CLI連携サーバー `127.0.0.1:8765` は、iPhoneからはそのまま利用できません。

## データ・制約
- 株価指標は、利用者が取り込んだCSV内のデータだけから計算します。データがない場合は `—` と表示します。
- 20日平均線は直近20件以内の利用可能な終値平均、20日騰落率は20取引日前相当の終値と比較します。
- データはブラウザーのlocalStorageに保存されます。大きなCSVを大量に入れると保存容量を超える場合があります。
- Yahoo!ファイナンスはリンク連携であり、リアルタイム株価API接続ではありません。
- J-Quants API直接接続は既存パネルを維持していますが、APIキー/CORS/契約条件は環境依存です。APIキーを共有したり、HTMLに埋め込んだりしないでください。

## 構成
- `index.html`: UI
- `styles/app.css`: デザインとレスポンシブ表示
- `src/app.js`: 既存アプリの表・チャート等の処理
- `src/watchlist.js`: ウォッチリスト、CSV取込、スクリーニング
- `manifest.webmanifest`, `sw.js`, `icon.svg`: PWA関連
